# Python untuk Pemula

Praktikum Materi 02 (Santrikoding) dengan alur Git per bab. Dikerjakan di Arch Linux (WSL2) dengan Python 3.14.9 dan virtual environment.

## Ringkasan Materi

- Bab 1: Pengenalan dan instalasi Python (hello_world.py)
- Bab 2: Variabel dan tipe data: int, float, str, bool
- Bab 3: Operator aritmatika, perbandingan, dan logika
- Bab 4: Kondisi if, elif, else
- Bab 5: Perulangan for, while, break, continue
- Bab 6: List dan dictionary
- Bab 7: Function: parameter, return, nilai default
- Bab 8: Class dan object: method dan pewarisan
- Bab 9: pip dan virtual environment
- Bab 10: Konfigurasi environment dan IDE (VS Code)

## Cara Menjalankan

1. Clone repositori ini lalu masuk ke foldernya
2. Buat virtual environment: python -m venv venv
3. Aktifkan: source venv/bin/activate
4. Pasang library: pip install -r requirements.txt
5. Jalankan program, contoh: python hello_world.py

## Struktur

- Berkas .py: kode latihan tiap bab
- screenshots/: bukti hasil eksekusi program
- KONFIGURASI_IDE.md dan .vscode/: konfigurasi editor
- requirements.txt: daftar library
